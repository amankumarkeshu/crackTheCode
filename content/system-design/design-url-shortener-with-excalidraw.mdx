## 1. Problem Statement & Requirements

### Functional Requirements
- **Shorten URLs**: Convert long URLs to short URLs (e.g., `https://example.com/very/long/url` → `https://short.ly/abc123`)
- **Redirect**: When user visits short URL, redirect to original URL
- **Custom URLs**: Allow users to create custom short URLs
- **Analytics**: Track click counts, geographic data, referrer information
- **Expiration**: Support URL expiration dates

### Non-Functional Requirements
- **Scale**: 100M URLs shortened per day, 10:1 read/write ratio
- **Latency**: Redirect latency < 100ms at 95th percentile
- **Availability**: 99.9% uptime
- **Durability**: URLs should not be lost

## 2. Capacity Planning

### Traffic Estimates
- **Write QPS**: 100M URLs/day ≈ 1,200 writes/second
- **Read QPS**: 1B redirects/day ≈ 12,000 reads/second
- **Peak Traffic**: 2-3x average = 3,600 writes/sec, 36,000 reads/sec

### Storage Estimates
- **URL Storage**: Assuming 2KB per URL record → 200GB/day
- **5-year retention**: 365TB total storage needed
- **Cache Requirements**: 80/20 rule → cache 20% of hot URLs

## 5. URL Encoding Algorithm

### Base62 Encoding Approach

```python
class URLShortener:
    BASE62 = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"
    
    def encode_id(self, id: int) -> str:
        """Convert numeric ID to base62 string"""
        if id == 0:
            return self.BASE62[0]
        
        result = ""
        while id > 0:
            result = self.BASE62[id % 62] + result
            id //= 62
        return result
    
    def generate_short_code(self, long_url: str, user_id: int = None) -> str:
        # Generate unique ID using distributed ID generator
        unique_id = self.get_next_id()
        return self.encode_id(unique_id)
```

### Cache Implementation

```python
class URLCache:
    def __init__(self):
        self.redis_client = redis.Redis(host='redis-cluster')
        self.local_cache = {}
        
    async def get_url(self, short_code: str) -> Optional[str]:
        # L1: Application cache (fastest)
        if short_code in self.local_cache:
            return self.local_cache[short_code]
        
        # L2: Redis cache (fast)
        url = await self.redis_client.get(f"url:{short_code}")
        if url:
            self.local_cache[short_code] = url
            return url
            
        # L3: Database (slowest)
        url = await self.db.get_url_by_code(short_code)
        if url:
            # Cache with TTL
            await self.redis_client.setex(f"url:{short_code}", 3600, url)
            self.local_cache[short_code] = url
        
        return url
```

### Cache Eviction Strategy
- **LRU** for application-level cache
- **TTL-based** for Redis (1 hour for hot URLs)
- **Write-through** caching for new URLs

### Rate Limiting

```python
class RateLimiter:
    async def is_allowed(self, user_id: str, endpoint: str) -> bool:
        key = f"rate_limit:{endpoint}:{user_id}"
        current = await self.redis.get(key) or 0
        
        limits = {
            'free_user': {'shorten': 100, 'window': 3600},  # 100/hour
            'pro_user': {'shorten': 10000, 'window': 3600}   # 10K/hour
        }
        
        user_limit = limits[self.get_user_plan(user_id)]
        
        if int(current) >= user_limit['shorten']:
            return False
            
        # Increment counter with expiration
        await self.redis.incr(key)
        await self.redis.expire(key, user_limit['window'])
        return True
```

## 12. Security Considerations

### Security Measures

1. **Input Validation**
   - Validate URLs against malicious patterns
   - Rate limiting to prevent abuse
   - CAPTCHA for suspicious traffic

2. **Spam Prevention**
   - Blacklist known malicious domains
   - Machine learning models for spam detection
   - User reputation scoring

3. **Data Protection**
   - Encrypt sensitive data at rest
   - Use HTTPS for all communications
   - Regular security audits

```python
class SecurityValidator:
    BLOCKED_DOMAINS = ['malicious-site.com', 'spam-domain.net']
    
    def validate_url(self, url: str) -> bool:
        # Check URL format
        if not self.is_valid_url(url):
            return False
            
        # Check against blacklist
        domain = self.extract_domain(url)
        if domain in self.BLOCKED_DOMAINS:
            return False
            
        # Check with security service
        return self.security_service.is_safe(url)
```
